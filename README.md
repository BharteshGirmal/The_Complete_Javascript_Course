# 📘 The Complete JavaScript Course: Projects & Concepts

A comprehensive set of JavaScript learning modules and projects covering fundamentals through advanced topics. The repository includes clean examples for DOM manipulation, data structures, modern ES6+ concepts, asynchronous flows, and real-world apps built from scratch.

---

## 📂 Repository Overview

This repo follows a structure aligned with topics and mini-projects, composed of:

- **Fundamentals Part‑1 & Part‑2**: JavaScript basics  
- **Developer Skills**: Tooling, best practices, editor setup  
- **HTML & CSS**: Introductory UI styling fundamentals  
- **DOM Manipulation / Projects**: Hands-on DOM interaction  
- **Advance DOM**: Event handling and complex UI logic  
- **Data Structures in JS**: Arrays, objects, maps, sets  
- **NumberDatesTimers**: Working with built-in JS APIs  
- **OOP in JavaScript**: Prototypes, classes, advanced object design  
- **Primitives, Objects, Reference vs Value**: Memory-handling concept  
- **RegFunArrowFun**: Functions, arrow syntax, and binding  
- **Scopes & This Keyword**: Lexical vs dynamic context  
- **Default Parameters**  
- **Async Await Ajax**: Asynchronous programming, promises, AJAX  
- **Modern JavaScript Development**: Modules, bundlers, tooling  
- **Mapty App**: Geolocation-based workout tracker (project)  
- **forkify**: Interactive recipe app (project)

---

## 🌟 Key Highlights & Projects

- **Mapty App**: JavaScript-based geolocation and workout tracker using OOP principles and DOM control.
- **forkify**: Modern recipe app with search, API integration, and dynamic UI components.
- **Advanced DOM Modules**: In-depth manipulation, event handling, form control, and UI updates.
- **Async/Await Projects**: Practical AJAX examples, fetching JSON data, error handling, and Promises.

---

## 🧠 Learning Goals

- Master essential JavaScript fundamentals, including variables, loops, conditionals, and functions.
- Gain practical experience with the **DOM**, event listeners, and dynamic UI updates.
- Understand how **hoisting**, **scope**, and the **this keyword** affect code behavior.
- Write modern, maintainable code using **ES6+ syntax** and **object‑oriented JavaScript**.
- Build **asynchronous logic** using Promises, async/await, and AJAX API calls.
- Structure code using **modules and tooling**, making it production-ready.
- Build real-world projects like **Mapty** and **forkify** to showcase abilities.
